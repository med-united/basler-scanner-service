Document Upload with PoPP Token

Demonstrates POST /xds-document/upload with the PoPP validation filter enabled (POPP_AUTHORIZATION_FILTER_ENABLED=true). The filter parses the PoPP token (JWT) and rejects the request with 401 unless its patientId claim matches the kvnr query parameter.

Upload Task Status

The upload runs asynchronously — the task ID returned above only means the request was accepted. GET /xds-document/task/{taskId} returns the actual result as a RegistryResponseType (Success, InProgress or Failure with the error message). Note: a completed result is removed from the server after it has been fetched once.

Delete Document



    Uses the Server URL, PoPP token and KVNR from the form above.
    POST /xds-document/delete/raw — sends a RemoveObjectsRequest for the
    given entryUUID. Note: this is the id attribute of the ExtrinsicObject
    in the query response (urn:uuid:...), not the uniqueId used for download.
    The delete runs asynchronously — check the returned task ID in the Upload Task Status section.
